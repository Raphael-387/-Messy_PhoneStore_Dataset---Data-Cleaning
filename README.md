# 📱 Phone Store Dataset – Data Cleaning Project Using Excel

## 📌 Project Overview

This project focuses on cleaning and transforming a messy phone store dataset using Microsoft Excel and Power Query.

The dataset contained inconsistencies, duplicate records, unnecessary spaces, and other data quality issues that could affect the accuracy and reliability of business analysis.

The primary objective was to transform the raw dataset into a clean, consistent, structured, and analysis-ready dataset using Excel data-cleaning techniques and functions.

## 🎯 Project Objectives

- Identify and correct data quality issues.
- Remove duplicate records.
- Standardize text entries and inconsistent data.
- Clean unnecessary spaces and formatting errors.
- Use advanced lookup functions to retrieve and cross-reference information.
- Apply data validation to improve data accuracy.
- Use conditional formatting to identify inconsistencies and unusual values.
- Transform the dataset into a structured format suitable for further analysis.

## 🔍 Data Cleaning Process

### 1. Initial Data Inspection
- Examined the raw dataset to understand its structure.
- Identified missing values, inconsistencies and duplicate records.
- Reviewed columns for incorrect or inconsistent entries.

### 2. Removing Duplicates
- Identified duplicate records.
- Applied Excel's Remove Duplicates feature.
- Ensured records were not unnecessarily repeated.

### 3. Text Cleaning and Standardization
- Used the TRIM function to remove unnecessary spaces.
- Standardized inconsistent text entries.
- Improved consistency across relevant columns.

### 4. Advanced Lookup Functions
- Applied advanced lookup techniques to retrieve and match information across datasets.
- Used XLOOKUP and VLOOKUP where appropriate.
- Improved data consistency by cross-referencing related records.

### 5. Power Query Transformation
- Imported and transformed the dataset using Power Query.
- Cleaned and standardized relevant columns.
- Applied transformation steps to improve data quality.
- Prepared the dataset for further analysis.

### 6. Data Validation
- Applied data validation rules to restrict invalid entries.
- Improved data-entry consistency.
- Reduced the possibility of future data-quality issues.

### 7. Conditional Formatting
- Highlighted duplicate values and potential inconsistencies.
- Used visual formatting to identify data-quality issues.
- Made it easier to review and verify the cleaned dataset.

## 📊 Project Outcomes

The data-cleaning process helped to:

- Improve the overall quality and consistency of the dataset.
- Reduce duplicate records.
- Eliminate unnecessary spaces and formatting inconsistencies.
- Improve data matching and information retrieval.
- Establish better data-entry controls.
- Produce a structured dataset ready for further business analysis.
